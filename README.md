# LuarSystem - Desenvolvimento Digital

## Estrutura do Projeto

```
LuarSystem/
├── index.html              # Arquivo principal HTML
├── css/
│   └── styles.css         # Estilos CSS (separado)
├── js/
│   └── script.js          # Scripts JavaScript (separado)
├── assets/                # Pasta para imagens, fontes, etc
└── README.md              # Este arquivo
```

## Recursos Implementados

### ✅ Correções Realizadas

1. **Separação de Arquivos**
   - CSS extraído para `css/styles.css`
   - JavaScript extraído para `js/script.js`
   - HTML limpo em `index.html`

2. **Melhorias de Acessibilidade**
   - Adicionados atributos `aria-label` nas seções
   - Atributos `role` apropriados
   - `aria-hidden="true"` para elementos decorativos
   - Estrutura semântica com `<article>` e `<nav>`
   - IDs e `aria-labelledby` para associações
   - `rel="noopener noreferrer"` para links externos

3. **Melhorias de SEO**
   - Meta descrição adicionada
   - Meta keywords
   - Meta theme-color
   - Estrutura HTML5 apropriada

4. **Correções Técnicas**
   - Adicionado atributo `border: none` no `.btn` para evitar borda padrão
   - Links com `target="_blank"` e `rel="noopener noreferrer"` para segurança
   - Melhor organização semântica

## Como Usar

1. Abra o arquivo `index.html` em um navegador
2. Todos os estilos e scripts serão carregados automaticamente
3. O site é responsivo e funciona em dispositivos móveis
